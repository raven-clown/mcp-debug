# Code of Conduct

## Our pledge

We want this project to be a welcoming space for anyone contributing
or asking for help, regardless of experience level or background.

## Expected behavior

- Be respectful in issues, pull requests, and discussions.
- Give constructive feedback, and accept it in return.
- Focus criticism on the work, not the person.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Publishing others' private information without consent.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may remove comments, commits, or contributions that
violate this Code of Conduct, and may block repeat offenders from
the project.

## Reporting

Report issues by opening a private security advisory on the repo, or
by contacting a maintainer directly. Reports will be handled
confidentially.
