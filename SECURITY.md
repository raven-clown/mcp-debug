# Security Policy

## Supported versions

Only the latest published version on npm receives security fixes.

## Reporting a vulnerability

Do not open a public issue for security problems. Instead, email
ekdanai.kk@gmail.com with:

- a description of the issue
- steps to reproduce
- the version affected

You should get a response within a few days. Once a fix is
confirmed, a patched version will be published and the report can be
disclosed.
